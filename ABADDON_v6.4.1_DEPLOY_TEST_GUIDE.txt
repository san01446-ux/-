ABADDON v6.4.1 배포 및 테스트 순서

1. 권장 배포
- 전체본: 기존 저장소의 .git 폴더가 있는 루트에 압축을 풀어 덮어씁니다.
- 패치본: v6.4.0b가 정상 배포된 저장소에만 덮어씁니다.
- 운영 중인 survival_data.json, .env, Render 환경 변수는 ZIP에 들어 있지 않습니다.
- 배포 전에 Render Persistent Disk의 DATA_FILE 경로가 /var/data/survival_data.json인지 확인합니다.

2. Render 재시작 후 로그 확인
- v633_equipment_crafting import 구간에서 NameError가 없어야 합니다.
- 로그인 완료와 명령 동기화 로그까지 진행되는지 확인합니다.

3. 필수 읽기 전용 테스트
!테스트 상세
!안정화상태
!명령어
!안정화도움말

4. 신규 기능 테스트
!오늘할일
!서버브리핑
!서버테마
!서버테마미리보기 격리연구소
- 관리자: !서버테마설정 격리연구소
- 관리자: !데이터백업

5. 텍스트 우선 정책 확인
- !채집, !낚시, !광산: 결과는 나오되 게임 이미지가 붙지 않아야 합니다.
- !장비, !장비외형 장비명, !강화 장비명: 텍스트/이모지 결과만 나와야 합니다.
- !펫정보, !펫목록: 펫 정보는 나오되 이미지가 붙지 않아야 합니다.
- !카지노, !슬롯 10000: 결과 이미지는 붙지 않아야 합니다.
- !고철갈갈이 고철 50: 결과 이미지는 붙지 않아야 합니다.
- !월드보스: 기존 월드보스 이미지는 계속 표시되어야 합니다.

6. 오류 안내 확인
- 존재하지 않는 명령을 입력해 비슷한 명령 또는 !명령어 안내가 나오는지 확인합니다.
- 필수 인자가 필요한 명령을 값 없이 실행해 실제 사용법이 표시되는지 확인합니다.

7. 홈페이지
- 전체 업로드본은 정적 호스팅 루트에 그대로 업로드합니다.
- index.html, commands.html, updates.html에서 v6.4.1이 표시되는지 확인합니다.
- 모바일/데스크톱에서 메인 카드와 명령어 검색이 깨지지 않는지 확인합니다.

주의
- 이 빌드 환경에서는 discord.py 런타임과 실제 Discord 서버 연결이 없어 버튼 동시성, 권한, DM, 메시지 편집은 정적 검사만 가능합니다.
- 배포 서버에서 위 순서로 마지막 스모크 테스트를 진행해야 합니다.
