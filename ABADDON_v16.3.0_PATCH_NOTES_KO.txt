- 시즌 1 → 시즌 2 → 시즌 3 → 시즌 4 → 시즌 5 빠른 이동 버튼 추가
- 각 시즌의 상태·시작·선택·장면·기록·재시작·투표·결정 명령을 같은 흐름으로 정리

2. 전체 명령어 센터 전수 개편
- 소스 명령 선언 1,343개와 별칭 포함 접근 이름 2,979개 전수 검수
- 수동으로 작성된 일부 안내 목록 대신 실제 런타임 등록 명령을 자동 수집
- 메인 RPG / 플레이 / 세계 / 소셜 / 운영 5개 영역
- 43개 기능군으로 자동 분류
- 기능군별 25개 자동 페이지 분할
- 명령마다 짧은 설명, 직접 입력법, 별칭, 원본 기능군 표시
- 명령 선택 후 실제 실행 버튼 추가
- 필수 입력값이 있는 명령은 입력창으로 실행
- 전체 검색, 즐겨찾기 40개, 최근 실행 30개, 오늘 추천, 도시 공방, 자동 이모지 빠른 이동
- 기존 직접 명령과 별칭은 그대로 유지

- 각 부품을 512×512 투명 PNG로 전면 교체
- 부품 이름과 파일을 1:1로 연결
- 선택을 바꾸면 첨부 미리보기 이미지도 즉시 교체
- 상하좌우 이동, 확대, 축소, 적용, 복구, 도시 미리보기 버튼 제공
- 적용 결과에 어떤 행동을 했는지, 어떤 부품이 추가됐는지, 좌표·크기·전후 장식 수 표시
- 배치·복구 기록을 최근 100건 저장
- 도시 지도 레이어와 기존 저장 데이터 즉시 호환
