ABADDON v7.0.0 배포 후 권장 테스트

1. 기본 부팅
- Render 로그에서 Python 예외가 없는지 확인
- 기존 환경변수와 데이터 파일 경로 유지

2. 실전 월드보스
- !월드보스리셋 문지기
- !월드보스
- 서로 다른 직업의 계정으로 !월드보스공격 실행
- 약점 발동 문구와 실제 피해 증가 확인

3. 부위/페이즈
- !월드보스체력 50000
- 반복 공격으로 75%, 50%, 25% 구간 통과
- 페이즈 전환 배너와 수치 안내 확인
- 부위 파괴 후 상태 화면에서 실제 효과 문구 확인

4. 보상 큐 유실 방지
- 보스 HP를 낮춘 뒤 처치
- 보상을 받지 않고 새 보스 소환
- !월드보스보상목록 실행
- !월드보스보상 실행
- 새 보스가 활성 상태여도 이전 보상이 지급되는지 확인

5. 독립 테스트
- 실전 보스가 활성인 상태에서 !월드보스테스트 아틀라스
- !월드보스테스트상태
- !월드보스테스트공격
- 실전 보스 HP가 변하지 않는지 확인
- 식량, 내구도, 도감 수치가 변하지 않는지 확인
- !월드보스테스트종료

6. 영어 명령어 보존
- !worldboss
- !worldbossattack
- !worldbosscontribution
- 기존 6.5.4 영어 도움말 명령 확인

7. 최종 확인
- !패치에서 7.0.0 항목 확인
- !게임 월드보스 카테고리에서 보상 큐/테스트 설명 확인
- 봇 활동 상태가 실제 길드별 월드보스를 표시하는지 확인
