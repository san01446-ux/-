ABADDON v16.8.0 배포·테스트 가이드

1. 적용 전 백업
- .env 및 운영 환경 변수
- survival_data.json을 포함한 실제 저장 데이터
- 현재 정상 동작 중인 v16.7.1 전체 폴더
- 저장 데이터 파일은 새 ZIP의 예제 파일로 덮어쓰거나 삭제하지 마세요.

2. 적용
- 새 ZIP을 별도 폴더에 압축 해제합니다.
- apocalypse_bot 폴더와 v16.8.0 문서를 기존 저장소에 덮어씁니다.
- requirements.txt와 기존 환경 변수를 확인합니다.
- 실행 중인 봇 프로세스를 완전히 종료한 뒤 다시 시작합니다.

3. 홈페이지
- 홈페이지 ZIP을 해제한 전체 파일과 assets 폴더를 GitHub Pages 저장소 최상위에 덮어씁니다.
- 기존 도메인, terms.html, privacy.html 경로는 유지합니다.

4. 필수 실행 점검

5. 실제 진행 점검
- 생존자 난이도로 원정을 시작합니다.
- NPC 동료 2명을 선택합니다.
- 전진·수색·야영·특수 행동을 각각 눌러 봅니다.
- 봇을 재시작한 뒤 !원정이어하기로 복구되는지 확인합니다.
- 보스 실패 시 원정이 즉시 완주 처리되지 않는지 확인합니다.
- 철수와 구조에서 일부 전리품만 한 번 지급되는지 확인합니다.
- 결과에 획득·소모·HP·감염·사기·새 기록이 표시되는지 확인합니다.

6. 언어 점검
- 한국어 선택: 제목, 설명, 버튼, 드롭다운, 결과가 한국어만 표시
- English 선택: title, descriptions, buttons, dropdowns, results are English only
- 두 언어의 도감 저장 키는 공통이며 표시할 때만 선택 언어로 변환

7. 알려진 배포 환경 확인
제작 환경에는 discord.py 런타임과 실제 Discord 토큰이 없어 Gateway 접속, 권한 조합, 동시 버튼 클릭은 정적 검사만 수행했습니다. 실제 서버에서 최종 확인하세요.
