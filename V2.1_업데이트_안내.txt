아포칼립스 봇 V2.1 Apocalypse Reborn

업데이트 방법
1. Render를 먼저 중지하지 않아도 됩니다.
2. GitHub 저장소에서 기존 apocalypse_bot 폴더를 삭제합니다.
3. 이 압축파일의 apocalypse_bot 폴더를 통째로 업로드합니다.
4. 222.py와 requirements.txt도 덮어씁니다.
5. survival_data.json은 절대로 삭제하거나 교체하지 마세요.
6. GitHub 커밋 후 Render가 자동 재배포되면 완료입니다.

주의
- .env와 디스코드 토큰은 압축파일에 들어 있지 않습니다.
- 기존 유저 데이터는 새 필드가 자동 추가되는 마이그레이션 방식입니다.
- Render 영구 디스크가 없다면 재시작/재배포 때 survival_data.json 변경분이 사라질 수 있습니다.

V2.1 주요 내용
- 상태 메시지 18종 이상, 45초 간격 자동 변경
- 실제 등록 생존자 수, 서버 수, 길드 수, 거래소 매물 수, 월드보스 HP 연동
- 심층 던전 1~100층, 함정/보물방/구조신호/오염구역/히든보스
- 강화정보, 보호강화, 강화석, 강화보호권, 강화랭킹
- 장비 랜덤 옵션, 옵션 재설정, 세트 효과
- 월드보스 특수 패턴, 광폭화, 보스 도감
- 생활 숙련도 및 획득량 보너스
- 종합 랭킹
- 거래소 검색, 경매 등록, 입찰, 경매 마감, 거래 기록, 수수료
