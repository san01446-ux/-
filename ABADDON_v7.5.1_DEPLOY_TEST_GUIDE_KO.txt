ABADDON v7.5.1 Render 배포·실서버 테스트 가이드

1. 배포 전 백업
- 기존 Render Persistent Disk의 /var/data/survival_data.json을 별도 보관
- 현재 실행 중인 봇에서 !백업생성 후 !백업검증 실행
- 환경변수와 Persistent Disk 마운트 경로를 캡처 또는 기록
- 이번 패치는 데이터 삭제 0건이지만 원본 백업 없이 덮어쓰지 않기

2. 봇 파일 배포
- ABADDON_BOT_v7.5.1_RUNTIME_RAID_TACTICS_PATCH.zip의 내용물을 프로젝트 루트에 배포
- 루트에 다음 항목이 보여야 함
  222.py
  requirements.txt
  apocalypse_bot/
- Render 시작 명령을 python 222.py로 설정
- 토큰 환경변수는 DISCORD_TOKEN 권장, 기존 BOT_TOKEN 또는 TOKEN도 지원

3. 첫 부팅 로그 확인
- 다음 오류가 다시 나오면 안 됨
  RuntimeError: 게임 기능군 연결 오류
  duplicated=['guild_donate', 'guild_upgrade']
- 정상 코드에서는 기능 276개가 메뉴 276곳에 한 번씩 연결됨
- 혹시 배포 과정에서 메뉴 메타데이터가 섞이면 운영 모드는 아래와 비슷한 자동 복구 로그를 남기고 계속 부팅함
  [ABADDON v7.5.1] 게임센터 연결 자동 복구: ...
- SyntaxError, ImportError, CommandRegistrationError도 없어야 함

4. 엄격 검수 모드 선택 사항
- 스테이징 Render 서비스에서 ABADDON_STRICT_MENU_VALIDATION=1을 설정하면 메뉴 오류를 자동 복구하지 않고 즉시 실패시킴
- 배포 검수에는 유용하지만 운영 서비스에서는 기본값 0을 권장
- 엄격 모드 확인 후 운영 서비스에서는 해당 환경변수를 제거하거나 0으로 변경

6. 게임센터 회귀 검사
- !게임 또는 게임센터 메뉴 열기
- 길드 카테고리에서 길드 기부와 길드 강화가 각각 한 번만 보이는지 확인
- 길드 레이드 카테고리에서 준비, 전술 설정, 연습, 기록, 공격, 보상이 모두 보이는지 확인
- 메뉴에서 같은 기능이 두 번 보이거나 빠진 기능이 없는지 확인

7. 개인 전술 프리셋

!길드전술설정
- 두 번째 조회에서 지원·동력핵이 표시되는지 확인
- 봇 재시작 후에도 같은 설정이 유지되는지 확인

8. 레이드 준비 점검
!길드레이드준비
- 개인 전투력, 프리셋, 추천 목표, 행동 가능 시간, 시설 보정이 표시되는지 확인
- 길드 미가입 계정은 안내 메시지만 나오고 오류가 발생하지 않아야 함

9. 무상태 연습전 검사
- 실행 전 !길드레이드 화면과 survival_data.json 백업을 준비
!길드레이드연습
!길드레이드연습 지원 장갑판
- 연습 결과는 표시되지만 실제 보스 HP와 부위 HP가 줄지 않아야 함
- 실제 공격 쿨다운이 생기지 않아야 함
- 길드 기여도와 보상 수령 상태가 바뀌지 않아야 함
- 빠르게 연속 실행하면 10초 보호 대기시간이 표시되어야 함

10. 프리셋 실전 공격
- 실제 레이드 공격이므로 테스트 길드에서 진행
!길드전술설정 지원 동력핵
!길드레이드공격
- 인자 없이 실행했을 때 지원 전술과 동력핵 프리셋을 사용하는지 확인
- 저장된 부위가 이미 파괴된 상황에서는 남은 부위 자동 선택으로 진행되는지 확인
- 명령을 빠르게 중복 실행해도 쿨다운·잠금이 중복 피해를 막는지 확인

12. 길드·금고 회귀 검사
- 기존 길드 정보, 길드원, 기금/금고, 시설 레벨, 미션, 레이드 기록이 유지되는지 확인
- 테스트 계정으로 동시 입금·동시 보상 수령·동시 출금 승인을 재검사
- 같은 출금 요청과 레이드 보상이 두 번 지급되지 않아야 함

13. 스토리 회귀 검사

- 시즌 2 완료 후 시즌 3, 시즌 3 완료 후 시즌 4가 해금되는지 확인

- 관리자 계정은 모든 시즌을 바로 실행할 수 있어야 함
