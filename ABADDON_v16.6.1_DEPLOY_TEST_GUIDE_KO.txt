ABADDON v16.6.1 배포·테스트 가이드

[배포]
1. 기존 .env와 데이터 저장 폴더를 백업합니다.
2. v16.6.1 ZIP을 새 폴더에 압축 해제합니다.
3. 기존 .env와 데이터 파일만 새 폴더로 옮깁니다.
4. requirements.txt 의존성을 확인하고 봇을 재시작합니다.
5. 부팅 로그에서 v16.6.1 등록과 슬래시 명령 동기화를 확인합니다.

[오류 재현 경로 확인]
1. !명령어 → 플레이 → 장비/제작 → !장비 실행
2. !장비에서 카테고리를 여러 번 변경
3. !명령어에서 상위 버튼·기능군·명령 선택을 반복
4. !카지노게임 또는 !카지노 실행
5. !테스트 상세 실행

[합격 기준]
- _MissingSentinel object has no attribute author가 다시 발생하지 않음
- HTTP 400 code 50035 Invalid Form Body가 발생하지 않음
- CategorySelect NotFound가 사용자 오류 화면으로 노출되지 않음
- 한국어/English가 한 화면에서 혼합되지 않음
- 기존 저장 데이터와 주요 명령이 유지됨
