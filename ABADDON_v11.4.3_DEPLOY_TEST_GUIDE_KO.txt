ABADDON v11.4.3 배포·테스트 가이드

1. Render에 새 BOT ZIP을 배포하고 Clear build cache & deploy를 권장합니다.
2. 부팅 로그에서 아래 문장을 확인합니다.
   [ABADDON v11.4.3] disaster_alerts=server_opt_in default=off configured_channel_only=true
3. 알림을 원하지 않는 서버에서 !재난알림을 실행합니다.
   - 구독 안 함 / 자동 재난 꺼짐 / 채널 미설정 또는 기존 채널 표시가 정상입니다.
4. 알림을 원하는 테스트 서버에서 관리자 계정으로 실행합니다.
   !재난채널 #테스트채널
   !재난알림
5. 테스트 서버만 구독 중이고 지정 채널이 표시되는지 확인합니다.
6. 다른 서버에서는 자동 재난이 생성·게시되지 않는지 확인합니다.
7. 테스트 서버에서 필요하면 !재난발생 식량 저장고 부패로 수동 패널을 확인합니다.
8. !재난알림 끄기 후 자동 일정이 사라지는지 확인합니다.
9. !재난알림해제 후 구독·자동 발생·채널 설정이 모두 지워지는지 확인합니다.
10. 최종 검수:
    !재난알림검수 상세
    !테스트 상세
    !패치노트

주의
- 기존 메시지는 배포 전 상태를 유지할 수 있으므로 새 명령 메시지로 확인하세요.
- 수동 !재난발생은 관리자 요청이므로 구독이 꺼져 있어도 현재 채널에 표시됩니다.
- 실제 Discord Gateway 다중 서버 자동 스케줄은 운영 테스트 서버에서 최종 확인해야 합니다.
