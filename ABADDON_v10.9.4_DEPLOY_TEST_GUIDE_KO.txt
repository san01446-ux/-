ABADDON v10.9.4 배포·실제 테스트 가이드

1. Render에서 v10.9.4 ZIP을 배포합니다.
2. 이전 빌드가 계속 보이면 Clear build cache & deploy를 사용합니다.
3. 부팅 로그에서 아래 문장을 확인합니다.
   [ABADDON v10.9.4] image_tables=25 private_hands=enabled korean_font=auto layout=wrapped website_copy=simplified

[첫 점검]
!테스트 상세
!이미지검수 상세
!패치노트

[정보 PNG]
!정보
!세계지도
!카드대시보드
- 한글이 □로 나오지 않는지 확인
- 긴 닉네임과 큰 숫자가 박스 밖으로 나가지 않는지 확인
- !정보 카드에 실행자의 실제 Discord 표시 프로필이 들어가는지 확인

[카드게임 실전 점검]
1. !아바돈초대 고스톱 10000
2. !아바돈초대 텍사스홀덤 10000
3. !포커 10000
4. !섯다 10000
5. !원카드 10000
6. !조커잡기 10000
7. !카드블랙잭 10000
8. !카드바카라 10000
9. 신규 카드게임 중 1종

각 게임에서 확인할 항목:
- 상태가 바뀔 때 같은 Discord 메시지의 PNG도 갱신되는가
- 내 패 버튼이 본인에게만 PNG를 보여주는가
- 상대·관전자에게 비공개 패가 노출되지 않는가
- 버튼과 선택 메뉴가 계속 작동하는가
- 종료 시 승패·팟/점수·이번 손익·이전 잔액→현재 잔액이 표시되는가

[글꼴 문제 발생 시]
Render 이미지에 한글 글꼴이 없고 외부 다운로드가 차단된 경우 환경변수에 설치된 한글 글꼴 경로를 지정합니다.
ABADDON_DASHBOARD_FONT=/path/to/korean-regular.ttf
ABADDON_DASHBOARD_FONT_BOLD=/path/to/korean-bold.ttf

글꼴 파일은 배포 ZIP에 포함하지 않습니다.
