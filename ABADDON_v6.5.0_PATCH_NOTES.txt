ABADDON v6.5.0 — 월드·비주얼·테마 리뉴얼

1. 홈페이지 화면 맞춤
- 전체 이미지 max-width 100%, 카드 overflow hidden, min-width 0 적용
- 장비·보물·기지 이미지는 object-fit contain으로 잘림/튀어나감 방지
- 모바일·태블릿·데스크톱 반응형 레이아웃 보강

2. 기지 이미지 리마스터
- 단계 6장 + 반응 7장 총 13장
- 오래된 제목·화살표·잘린 문구 영역 제거
- 1920x1080 Lanczos 업스케일, 노이즈 완화, 명암/선명도 보정

3. 강화 이펙트 재설계
- +0~+4 원본 픽셀 유지
- +5 테두리, +10 외곽 광점, +15 계열별 모서리 효과, +20 초월 룬
- 중앙 피사체를 가로지르는 초록 사선/공통 레이저 제거
- 근접 장비는 금속성 금빛 효과 사용

4. 서버 테마 28종
- 기존 아포칼립스 12종 유지
- 깔끔·고딕 4종, 화사·자연 6종, 모던·판타지 6종 추가
- !서버테마 분류 검색과 !서버테마설정 유지

5. 이미지 정책
- 생활·장비·보물·제작·펫·기지·갈갈이·월드보스 이미지 유지
- 카지노만 이미지 미사용
- !명령어 드롭다운과 홈페이지 명령어 검색 최신화
