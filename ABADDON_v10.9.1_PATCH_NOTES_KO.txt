ABADDON v10.9.1 카드 대시보드 · discord.py UI 로그 핫픽스
패치일: 2026-08-03

1. 카드게임 25종 상세 임베드 대시보드
- 신규 명령: !카드대시보드
- 별칭: !카드도감
- 영문: !carddashboard / !cardcatalog / !cardgamesdashboard
- 포커 계열, 한국 카드·화투, 카지노·토너먼트, 파티·조합의 4개 영역으로 분류합니다.
- 게임을 선택하면 규칙, 참가 인원, 실제 진행 방식, 최소 판돈, 일반 방 명령, ABADDON 대전 명령, 최종 결과 표시 항목을 한 화면에 보여줍니다.
- Discord 선택 메뉴 최대 25개 제한에 맞춰 정확히 25종을 한 메뉴에서 제공합니다.

2. 대시보드에서 바로 게임 시작
- 상세 카드의 '게임방 만들기' 버튼으로 일반 모집방을 생성합니다.
- '아바돈 대전' 버튼으로 사람이 없어도 즉시 ABADDON과 시작합니다.
- 고스톱·육백 등 3인 종목은 기존 ABADDON-β 자동 보충 경로를 사용합니다.
- 판돈 입력은 음수 잔액 허용, 입력 상한 없음, 기존 최소 판돈 규칙을 유지합니다.

3. Render 로그의 DeprecationWarning 수정
- 원인: 공용 번역기가 모든 UI 요소의 .label을 읽고 수정하면서 discord.ui.TextInput.label까지 접근했습니다.
- discord.py 2.6 이상에서 TextInput.label은 폐기 예정이며 discord.ui.Label 사용이 권장됩니다.
- 수정: TextInput의 폐기 속성은 건드리지 않고 버튼·선택 메뉴·placeholder·옵션·현행 Label 컨테이너만 번역합니다.
- 신규 판돈 모달은 discord.ui.Label(text=..., component=TextInput(...)) 구조를 사용합니다.
- 기존 한국어/English 단일 언어 출력은 유지합니다.

4. 최신화
- !카드게임 실행 시 기존 빠른 시작 메뉴와 상세 카드 대시보드를 함께 안내합니다.
- !테스트 상세는 v10.9.1에서 수정한 카드 대시보드, 일반/AI 시작 경로, 언어 분리, UI 경고 제거만 검사합니다.
- !패치노트는 이번 핫픽스에서 실제 변경한 항목만 표시합니다.
- 공식 홈페이지 한국어 / English 페이지, 명령 설명, 업데이트 기록, 명령 매니페스트를 v10.9.1로 동기화했습니다.

5. 보존 사항
- 기존 카드게임 25종, 실전 규칙, 음수 잔액, 노리밋, 무상한 정산, 파산신청, 전적, 리플레이, 리그는 삭제하거나 초기화하지 않았습니다.
- 기존 저장 데이터 키와 이전 패치 파일은 유지됩니다.
