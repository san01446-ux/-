ABADDON v7.1.0 Render / 홈페이지 배포 테스트 가이드
====================================================

A. 배포 전
1. 현재 운영 봇에서 !백업생성 실행
2. !백업검증 실행
3. 최근 정상 백업 파일명을 별도로 기록
4. 기존 Render 배포 파일과 환경 변수를 보존

B. Render 봇 배포
1. ABADDON_BOT_v7.1.0_GROWTH_LOOP_PATCH.zip 압축 해제
2. requirements.txt와 apocalypse_bot 폴더가 프로젝트 루트에 오도록 업로드
3. 기존 Render 시작 명령과 환경 변수를 변경하지 않고 재배포
4. 부팅 로그에서 Python 예외와 Extension/Cog 등록 오류 확인

C. 필수 점검 순서
1. !시스템점검
2. !백업검증
3. !테스트 상세
4. !오늘할일
5. !성장보드
6. !출석, !채집, !낚시, !훈련 등 실제 행동 수행
7. !성장보드에서 ⬜ → 🟨 → ✅ 변화 확인
8. 6개 일일 항목 중 5개 완료 후 !미션보상 실행
9. !미션보상을 다시 실행하여 중복 수령이 차단되는지 확인
10. !장비프리셋 저장 테스트 / !장비프리셋 목록 / 적용 테스트
11. 월드보스 실전 공격 후 !월드보스주간랭킹 반영 확인
12. 테스트 월드보스 공격이 주간 랭킹에 포함되지 않는지 확인

D. 홈페이지 배포
1. ABADDON_OFFICIAL_SITE_v7.1.0_UPLOAD.zip 압축 해제
2. index.html, commands.html, updates.html, config.js, script.js, style.css, assets 폴더를 웹 루트에 업로드
3. 브라우저에서 Ctrl+F5 또는 강력 새로고침
4. v7.1.0 표기와 신규 명령어 7종 검색 확인
5. 기존 이미지가 그대로 표시되는지 확인

E. 데이터 이관 주의
- 기존 사용자 데이터는 명령 실행 시 v7.1.0 성장 상태가 지연 생성됩니다.
- 현재 주차의 월드보스 기록은 기존 누적 피해에서 가능한 범위로 초기 이관됩니다.
- v7.1.0 적용 이후의 월드보스 공격부터 정확한 주간 기록으로 집계됩니다.
- 복귀 보급의 14일 미접속 판정은 v7.1.0이 last_seen_at을 기록한 뒤부터 완전하게 작동합니다.

F. 롤백
1. Render에서 v7.0.2 배포본으로 되돌림
2. 필요 시 !복구미리보기로 정상 백업 확인
3. 봇이 실행 중인 상태에서 데이터 파일을 수동 덮어쓰지 않기
4. 점검 시간에 봇을 중지한 뒤 검증된 백업만 복원

검증 범위
- 전체 Python 정적 컴파일
- v7.1.0 모듈 격리 실행 테스트
- 중복 보상 차단
- 프리셋 저장/적용
- 월드보스 주간 기록 및 진행 중 주차 이관
- 홈페이지 JavaScript 문법과 로컬 링크
- 이미지 파일 무변경 비교

제한 사항
- 이 작업 환경에서는 Discord 로그인과 Render 실서버 부팅을 수행하지 않았습니다.
- discord.py 패키지를 외부에서 설치할 수 없는 환경이어서 실제 Discord 이벤트 연결은 배포 후 스테이징에서 확인해야 합니다.
