ABADDON v11.5.0 배포 및 실제 서버 테스트 가이드

1. 배포
- 기존 저장 데이터와 환경변수를 백업합니다.
- BOT ZIP을 배포 저장소에 덮어씁니다.
- Render를 사용한다면 Clear build cache & deploy를 권장합니다.
- 부팅 로그에서 다음 문구를 확인합니다.
  [ABADDON v11.5.0] server_operations=enabled alerts=per_guild permissions=backup_first bot_audit=all rollback=enabled

2. 읽기 전용 검수
!테스트 상세
!서버설정검수 상세
!패치노트
!서버운영
!서버봇목록
!서버봇권한검수 상세

3. 알림 구독 테스트
- 테스트용 텍스트 채널에서 실행합니다.
!서버설정백업
!서버알림 재난 켜기 #테스트채널
!서버알림 패치 켜기 #테스트채널
!알림시간 00:00 23:59
!알림테스트 재난
!알림테스트 패치
- 테스트 메시지가 지정 채널에만 표시되는지 확인합니다.
- 비구독 서버에는 자동 알림이 게시되지 않는지 확인합니다.

4. ABADDON 권한 자동 설정 테스트
- 먼저 미리보기만 실행합니다.
!권한자동설정 미리보기
- 분류가 예상과 맞는지 확인한 뒤 테스트 서버에서만 적용합니다.
!권한자동설정 적용
- 출력된 P-XXXXXXXX 복구 ID를 기록합니다.
- 알림 채널에서 메시지/임베드/첨부, 게임 채널에서 이미지와 버튼, 음성 채널에서 연결/말하기를 확인합니다.
- 복구 테스트:
!권한복구 P-XXXXXXXX

5. 다른 봇 권한 테스트
- 먼저 목록과 검수만 실행합니다.
!서버봇목록
!서버봇권한검수 상세
- 테스트용 봇과 테스트 채널을 명시적으로 선택합니다.
!봇권한적용 @테스트봇 읽기전용 #테스트채널
- 복구 ID로 즉시 원상복구합니다.
!권한복구 P-XXXXXXXX

6. 서버 설정 복구 테스트
!서버설정백업
!알림시간 09:00 22:00
!서버알림 퀴즈 켜기 #테스트채널
!서버설정복구목록
!서버설정복구 S-XXXXXXXX
- !서버운영에서 이전 시간/채널/구독 상태가 복구됐는지 확인합니다.

7. 주의
- 권한 적용은 서버 소유자 또는 서버 관리 권한 사용자만 실행할 수 있습니다.
- ABADDON에 역할 관리 권한이 없거나 역할이 대상 봇보다 낮으면 적용이 차단됩니다.
- 카테고리 동기화 권한은 별도로 건드리지 않고 각 채널의 봇 멤버 덮어쓰기만 변경합니다.
- 실제 Discord의 역할 계층과 채널 상속 상태에 따라 결과가 달라질 수 있습니다.
