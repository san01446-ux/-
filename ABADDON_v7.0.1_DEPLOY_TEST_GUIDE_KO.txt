ABADDON v7.0.1 배포 및 확인 가이드

[봇 / Render]
1. ABADDON_BOT_v7.0.1_COMMAND_UX_PATCH.zip의 내용을 기존 Render 저장소 루트에 덮어씁니다.
2. requirements.txt와 apocalypse_bot 폴더가 저장소 최상단에 있는지 확인합니다.
3. 기존 환경 변수와 데이터 디스크 설정은 변경하지 않습니다.
4. 재배포 후 Discord에서 아래 순서로 확인합니다.
   - !처음
   - !명령어
   - !명령어 강화
   - !게임
   - !게임 → 장비 → 강화·옵션
   - !게임 → 생활 → 기지·세계
   - !게임 → 처음 시작
   - !게임 → 오늘 추천
5. 장비·생활 드롭다운이 오류 없이 열리고 모든 기능군이 25개 이하인지 확인합니다.
6. 기존 명령어 예시(!월드보스, !카지노, !스토리, !알림설정)도 계속 실행되는지 확인합니다.

[홈페이지]
1. ABADDON_OFFICIAL_SITE_v7.0.1_UPLOAD.zip을 홈페이지 루트에 덮어씁니다.
2. 브라우저에서 Ctrl+F5로 캐시를 갱신합니다.
3. 상단 LATEST가 v7.0.1인지 확인합니다.
4. commands.html에서 목적별 버튼, 대표/전체 전환, 검색, 명령 복사를 확인합니다.
5. 모바일 화면에서 목적 버튼과 명령 카드가 한 열 또는 두 열로 정상 배치되는지 확인합니다.

[롤백]
- 문제가 생기면 직전 v7.0.0 봇 ZIP과 홈페이지 ZIP으로 되돌립니다.
- 이번 패치는 저장 데이터 형식을 변경하지 않으므로 코드 롤백 시 데이터 마이그레이션이 필요하지 않습니다.
