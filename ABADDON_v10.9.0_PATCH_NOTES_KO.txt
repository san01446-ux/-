ABADDON v10.9.0 카드·대시보드·리그 통합 리뉴얼 패치노트
배포 기준일: 2026-08-03

[핵심 복구]
- 카드게임 종료 후 승부 결과가 표시되지 않던 경로를 수정했습니다.
- 종료 카드에 승패, 공개 가능한 족보/점수, 팟 또는 정산 기준, 이번 게임 증감액, 이전 잔액 → 현재 잔액을 표시합니다.
- 기존 결과 메시지 편집이 실패하거나 메시지가 삭제된 경우 새 최종 결과 임베드를 전송합니다.
- 원카드·조커잡기·포커 계열·블랙잭·바카라·섯다·맞고/고스톱·v10.9 신규 게임 정산 경로에 동일한 결과 원칙을 적용했습니다.

[신규 실전 카드게임 9종]
- 훌라: 뽑기 → 세트/런 조합 → 버리기, 첫 등록 30점, 손패 소진 승리.
- 라미: 10장 시작, 세트 또는 같은 무늬 연속 조합을 등록하고 손패를 먼저 비웁니다.
- 대통령: 같은 숫자 묶음, 패스, 같은 장수의 더 높은 패, 4장 혁명 규칙.
- 주사위카드: 개인 카드 2장과 주사위 3개를 합친 족보, 선택 재굴림 최대 2회.
- 삼봉: 화투 3장 공개 단계와 노리밋 체크/콜/레이즈/폴드.
- 도리짓고땡: 5장 중 합이 10의 배수인 메이드 2장과 남은 3장 족보.
- 민화투: 손패 내기, 바닥 월 맞추기, 더미 뒤집기, 고/스톱 없는 획득 점수전.
- 육백: 민화투식 유효 라운드 점수를 누적해 600점 선취.
- 블랙잭 토너먼트: 같은 참가자로 5핸드 진행, 핸드별 누적 점수로 전체 팟 승자 결정.

[아바돈 AI]
- 기존 16종과 신규 9종을 합친 카드게임 25종 모두 아바돈 초대를 지원합니다.
- 3인 종목은 사람이 부족할 때 ABADDON과 ABADDON-β 좌석을 채웁니다.
- AI 난이도 4단계와 성향 5종을 설정할 수 있습니다.

[카드룸·관전·리플레이]
- 모집 중/진행 중 테이블 대시보드, 빠른 참가, 재대결을 추가했습니다.
- 관전자는 턴, 팟, 바닥패 등 공개 정보만 확인하며 비공개 손패는 저장·표시하지 않습니다.
- 최근 게임과 번호별 리플레이를 단계별 기록으로 확인합니다.

[정보 대시보드]
- 생존자, 게임, 경제/부채, 세계, 지도, 동료, 연합, 시즌, 리그, 최신 테스트, 패치노트를 Discord 임베드 카드형 화면으로 정리했습니다.
- `!정보리뉴얼현황`에서 리뉴얼 완료 영역과 아직 기존 화면을 사용하는 영역을 확인할 수 있습니다.
- 아직 기존 화면 유지: 개별 상점 카탈로그, 상세 장비/보물 도감, 음성/TTS 설정, 채널 설치 미리보기, 일부 원시 관리자 로그.

[부채·리그]
- 음수 칩, 노리밋 베팅, 배수/정산 무상한 규칙을 그대로 유지합니다.
- 부채 기록, 파산 대시보드, 일일 재기임무를 추가했습니다.
- 카드 리그, 주간 랭킹, 명예의 전당, 대회 센터를 추가했습니다.

[최신 패치 검수]
- `!테스트 상세`는 과거 전체 기능이 아니라 v10.9.0에서 추가·수정한 기능만 검사합니다.
- 이후 패치에서는 이 검수 목록도 최신 패치 범위로 교체하도록 연결했습니다.
- `!패치노트`, 명령 설명, 한국어 홈페이지, English 홈페이지, 명령 매니페스트를 v10.9.0으로 동기화했습니다.

[언어 표시]
- 한국어 선택자는 한국어 명령·버튼·설명만 표시합니다.
- English 선택자는 English command, button, and description only를 표시합니다.
- 내부 기능과 저장 데이터는 공유하지만 두 언어를 한 화면에 섞지 않습니다.

[중요]
- Python 컴파일, 순수 규칙 테스트, 정적 통합 검사, 명령 충돌, 홈페이지 링크/HTML/JS/JSON, 기존 파일 보존, ZIP 무결성을 검사했습니다.
- 제작 환경에는 discord.py 런타임과 실제 Discord 토큰이 없어 로그인·권한·버튼 동시 클릭은 자동 실행하지 못했습니다. 배포 가이드의 테스트 서버 절차를 반드시 진행하세요.
