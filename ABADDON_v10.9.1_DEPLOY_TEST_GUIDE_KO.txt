ABADDON v10.9.1 배포 및 라이브 테스트 가이드

1. 배포
- 기존 운영 폴더와 데이터 파일을 백업합니다.
- v10.9.1 봇 압축파일을 기존 프로젝트에 덮어씁니다.
- requirements.txt의 discord.py==2.7.1을 유지합니다.
- 기존 환경 변수와 Discord 토큰은 변경하지 않습니다.
- Render 또는 운영 환경에서 재배포합니다.

2. 시작 로그 확인
정상 시작 시 아래와 비슷한 로그가 추가됩니다.
[ABADDON v10.9.1] card_dashboard=25 label_deprecation=safe latest_audit=12

기존에 반복되던 아래 경고가 새 상호작용 뒤 다시 발생하지 않아야 합니다.
DeprecationWarning: label is deprecated, use discord.ui.Label instead.
v1000_global_survivor.py:430~433

4. 카드 대시보드 라이브 테스트

5. 로그 재현 검사

주의
오프라인 제작 환경에는 discord.py와 실제 Discord 토큰이 없어 Gateway 로그인과 실제 버튼 클릭을 자동 실행하지 못했습니다. Python 컴파일, 순수 규칙 테스트, 폐기 속성 접근 방지 모의 테스트, HTML/JS/JSON, 링크, 언어 분리, 압축 무결성은 자동 검사했습니다.
