ABADDON V3.4 - 슬래시 명령어 병행 지원 안내
================================================

[변경 내용]
- 기존 !명령어는 삭제하지 않았습니다.
- 기존 명령어 전부를 / 슬래시 명령어로도 사용할 수 있게 추가했습니다.
- 봇 시작 시 Discord 전역 슬래시 명령어를 자동 동기화합니다.
- Discord의 최상위 슬래시 명령어 개수 제한 때문에 일부 명령어는 카테고리 그룹으로 묶었습니다.

[사용 예시]
- !정보 / /정보
- !탐색 왼쪽 100 / /탐색
- !직업목록 / /직업 목록
- !지역이동 폐허도시 / /지역 이동
- !침공공격 / /침공 공격
- !도감보상 / /도감 보상
- !스토리 시작 / /스토리 시작

[그룹형 슬래시 명령어]
- /직업 : 목록, 선택, 정보, 변경
- /의료 : 의약품, 구매, 사용, 병원, 상태, 휴식
- /지역 : 목록, 정보, 이동, 좀비도감, 탐색
- /퀴즈 : 오늘, 정답, 랭킹, 추가, 삭제, 목록, 알림설정, 알림해제, 알림상태
- /강화기능 : 정보, 보호강화, 랭킹, 장비옵션, 옵션재설정, 세트효과
- /심층 : 던전, 던전기록, 보스도감, 생활숙련도, 종합랭킹
- /경매 : 검색, 등록, 입찰, 마감, 기록
- /침공 : 현황, 참전, 공격, 랭킹, 기록, 상점, 시작, 종료, 토큰지급
- /관리 : 관리자 전용 명령어
- /서버 : 설정, 채널, 기능
- /튜토리얼 : 상태, 건너뛰기
- /도감 : 전체, 장비, 펫, 몬스터, 보상
- /스토리 : 상태, 시작, 선택, 기록, 재시작
- /rpg : 안내, start

[실행 순서]
1. 기존 .env 파일과 데이터 파일을 새 폴더에 옮깁니다.
2. requirements.txt 설치:
   py -3 -m pip install -r requirements.txt
3. 봇 실행:
   py -3 222.py
4. 콘솔에 "슬래시 명령어 동기화 완료"가 출력되는지 확인합니다.
5. Discord 채팅창에 /를 입력해 아바돈 명령어가 나타나는지 확인합니다.

[주의]
- 전역 슬래시 명령어는 Discord에 반영되기까지 시간이 걸릴 수 있습니다.
- 실행 콘솔에 "슬래시 명령어 동기화 실패"가 나오면 그 오류 전체를 확인해야 합니다.
- 기존 !명령어를 계속 쓰려면 Developer Portal의 Message Content Intent 설정이 필요합니다.
