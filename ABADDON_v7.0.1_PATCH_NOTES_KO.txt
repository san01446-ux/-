ABADDON v7.0.1 — 초보자 접근성 · 명령어 가시성 패치
패치 날짜: 2026-08-03

[핵심 변경]
1. !처음 / !초보 / !초보가이드
- 가입, 정보 확인, 직업 선택, 일일 보상, 첫 전투를 5단계로 안내합니다.

2. !게임 제어실 재구성
- 227개 게임 기능을 12개 카테고리 → 33개 기능군 → 실행 항목으로 정리했습니다.
- 처음 시작, 오늘 추천, 성장, 전투, 재화, 스토리, 함께하기 빠른 경로를 제공합니다.
- 즐겨찾기, 최근 실행, 검색, 실행 전 미리보기를 유지합니다.

3. Discord 드롭다운 제한 해결
- 기존 장비 26개, 생활 35개 항목이 Select 최대 25개를 초과할 수 있던 구조를 수정했습니다.
- 모든 기능군은 최대 14개 항목이며 25개 제한을 준수합니다.

4. !명령어 / !도움말 통합
- 처음 시작, 오늘 할 일, 카테고리, 대표 명령, 전체 목록, 검색을 한 브라우저에서 제공합니다.
- 카테고리를 열면 대표 명령만 먼저 보여주고 필요할 때 전체 목록을 펼칩니다.

5. 유사 명령어 정리
- 월드보스, 알림, 카지노, 스토리, 은행·대출, 서버 관리 기능을 대표 메뉴 아래 기능군으로 묶었습니다.
- 기존 세부 명령어와 v6.5.4 영어 별칭은 삭제하지 않고 호환용으로 유지합니다.

6. 홈페이지 v7.0.1 동기화
- 처음 시작 3대 명령, 목적별 필터, 대표/전체 전환, 명령 복사 버튼을 추가했습니다.
- 검색창은 명령어 이름이 아닌 “무엇을 하고 싶은지” 입력하도록 안내합니다.
- CSS/JS/이미지 캐시 키를 v701로 갱신했습니다.
