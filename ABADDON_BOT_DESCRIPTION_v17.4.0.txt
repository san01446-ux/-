ABADDON v17.4.0 — SYSTEM FUSION

시즌 1부터 시즌 6까지 이어지는 아포칼립스 RPG, 살아 있는 세계, 솔로 원정, NPC 인연, 도시 공방, 제작, 카지노와 일반 도박을 하나의 생존 흐름으로 연결한 Discord RPG 봇입니다.

v17.4.0은 기존 명령과 저장 데이터를 삭제하지 않고 다음 통합 기능을 추가합니다.
- 생존단말기: 스토리·세계·의뢰·원정·NPC·도시 효과와 다음 행동 통합 표시
- 생존 의뢰소: 세계 상태 기반 일일 3개·주간 1개 의뢰
- 세력 평판 5종: 의뢰 결과를 NPC 관계와 세계 지표에 연결
- 생산센터: 채집·가방·제작·재료 사용처·도시 배치 통합
- 한국어 선택 시 한국어만, English 선택 시 English only
