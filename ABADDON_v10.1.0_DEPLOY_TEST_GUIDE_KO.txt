ABADDON v10.1.0 배포·테스트 가이드

1. 배포 전 백업
- 기존 봇 폴더 전체와 실제 저장 데이터 파일을 별도 위치에 복사합니다.
- .env, 토큰, 서버별 설정, 사용자 저장 데이터는 덮어쓰기 전에 반드시 보관합니다.

2. 봇 파일 반영
- 이 압축파일을 새 폴더에 풀어 실행하는 방식을 권장합니다.
- 기존 설치에 덮어쓸 경우 .env와 운영 저장 데이터가 보존됐는지 확인합니다.
- requirements.txt 기준 의존성을 설치합니다.

3. 시작 로그 확인
- [ABADDON v10.1.0] companions=6 card_games=8 deletions=0
- [ABADDON v10.1.0] full English sync ... missing=0
위 로그가 보이고 Traceback이 없어야 합니다.

4. 한국어 화면 점검
- !언어 → 한국어 선택
- !카드게임: 한국어 버튼·설명·입력창만 표시되는지 확인
- !텍사스홀덤 10000: 2명 참가 후 시작, 개인 패 확인, 플랍/턴/리버, 승부 공개
- !오마하홀덤 10000: 결과 패가 개인 패 정확히 2장과 보드 정확히 3장인지 확인
- !세븐카드스터드 10000: 공개 단계와 최종 7장 평가 확인
- !맞고 10000: 2명만 시작되는지, 패 내기와 고/스톱 확인
- !고스톱 10000: 3~4명만 시작되는지 확인
- !동료, !동료영입, !동료배치, !동료대화, !동료임무 확인

5. 영어 화면 점검
- !language → English 선택
- !cardgames, !texasholdem 10000, !omahaholdem 10000, !sevencardstud 10000, !matgo 10000, !gostop 10000 실행
- 공개 패널, 개인 패, 버튼, 드롭다운, 모달, 오류 안내에 한글이 섞이지 않는지 확인
- !companions, !recruitcompanion Captain Min-jae, !assigncompanion Ira expedition, !companionmission 확인

6. 안전 처리 점검
- 참가비 부족 사용자의 시작 차단
- 같은 채널에서 두 번째 카드게임 생성 차단
- 모집방 취소 시 참가비 미차감
- 진행 중 시간 초과 시 참가비 환불
- 게임 종료 후 같은 버튼 재실행 시 중복 지급 없음
- 봇 재시작 뒤 기존 저장 데이터 유지

7. 검수 명령
- !1010안정화검수
- !카드게임검수
- !동료검수
- !홈페이지검수
- 기존 !1000안정화검수 및 !명령어검수도 함께 실행

8. 홈페이지 반영
- 홈페이지 압축파일의 내용을 웹 루트에 업로드합니다.
- 한국어: /index.html, /commands.html, /updates.html
- 영어: /en/index.html, /en/commands.html, /en/updates.html
- config.js와 en/config.js의 봇 초대 및 Discord 주소 확인
- 브라우저 캐시를 지우고 v10.1.0 표시와 명령 복사 버튼을 확인

9. 롤백
- 오류가 발생하면 봇을 중지하고 백업한 v10.0.0 코드와 저장 데이터를 복원합니다.
- 정산 도중 종료했다면 카드게임 예약 기록과 사용자 칩 잔액을 함께 확인합니다.

주의
- 자동 검수 환경에는 discord.py가 설치되어 있지 않아 실제 Discord 로그인·버튼 상호작용까지는 실행하지 못했습니다.
- 운영 적용 전 테스트 서버에서 위 라이브 점검을 반드시 완료하세요.
