ABADDON v7.1.1 Render / 홈페이지 배포 테스트 가이드
====================================================

A. 배포 전
1. 운영 서버에서 !백업생성 실행
2. !백업검증 실행
3. 현재 봇 역할에 역할 관리 권한이 있는지 확인
4. 봇 역할이 신규 생성될 새싹 역할보다 위에 있는지 확인
5. 기존 Render 환경 변수와 시작 명령 보존

B. Render 봇 배포
1. ABADDON_BOT_v7.1.1_CUTE_INTERACTION_PATCH.zip 압축 해제
2. requirements.txt와 apocalypse_bot 폴더가 프로젝트 루트에 오도록 업로드
3. 기존 환경 변수와 시작 명령을 유지하고 재배포
4. 부팅 로그에서 ImportError, CommandRegistrationError, View 오류 확인

C. 신규 멤버 기능 테스트
1. !시스템점검
2. !백업검증
3. !새싹역할설치
4. !새싹설정 기간 7
5. 환영 메시지를 보낼 채널에서 !새싹설정 환영채널
6. 테스트 계정으로 서버 재입장
7. `저 새로 들어왔어요, 환영해주세요!` 역할 부여 확인
8. 서버가 역할 아이콘을 지원한다면 이름 옆 🌱 표시 확인
9. 환영 패널의 가입·정보·출석·오늘 할 일·게임·명령어 버튼 확인
10. !새싹정리 실행 결과 확인

D. 명령어 인터랙션 테스트
1. !처음 실행 후 6개 버튼 확인
2. !명령어 또는 !귀여운메뉴 실행
3. 카테고리 드롭다운과 다음/이전 페이지 확인
4. 입력 없는 명령(예: !정보)을 버튼으로 실행
5. 입력 필요한 명령(예: !장비프리셋)을 모달로 실행
6. 검색 버튼에서 `월드보스`, `강화`, `백업` 검색
7. 기존 !접두사 직접 입력도 정상 동작하는지 확인
8. 버튼 실행 후 !성장보드 진행도가 정상 집계되는지 확인

E. 오류 복구 테스트
1. 존재하지 않는 명령을 입력하고 추천·명령어 찾기 버튼 확인
2. 필수 입력값을 빼고 실행해 재입력 모달 확인
3. 쿨타임 명령을 연속 실행해 남은 시간 안내 확인
4. !오류현황에서 새로운 사건 기록 여부 확인

F. 홈페이지 배포
1. ABADDON_OFFICIAL_SITE_v7.1.1_UPLOAD.zip 압축 해제
2. index.html, commands.html, updates.html, config.js, script.js, style.css, assets를 웹 루트에 업로드
3. 브라우저 강력 새로고침
4. v7.1.1 표기와 신규 명령 4종 검색 확인
5. 기존 이미지가 이전 버전과 동일하게 표시되는지 확인

G. 알려진 플랫폼 조건
- 역할 아이콘을 지원하지 않는 서버에서는 역할 이름과 색상만 적용됩니다.
- Discord는 일반 prefix 명령 텍스트를 사용자의 채팅 입력창에 자동 삽입하는 봇 API를 제공하지 않습니다. 이 패치는 버튼 즉시 실행과 입력 모달 방식으로 대체합니다.
- 역할 아이콘은 Discord가 한 사용자에게 표시할 수 있는 우선순위 역할 아이콘 규칙의 영향을 받습니다.

H. 롤백
1. Render에서 v7.1.0 배포본으로 되돌림
2. v7.1.1 데이터 키는 남아 있어도 이전 버전 기능에 영향을 주지 않음
3. 새싹 역할을 제거하려면 서버 역할 설정에서 수동 삭제하거나 배포 전 !새싹설정 끄기 실행
4. 데이터 복구가 필요한 경우 검증된 백업만 사용

검증 제한
- 작업 환경에서 Discord 계정 로그인과 Render 실서버 부팅은 수행하지 않았습니다.
- 외부 패키지 설치가 차단되어 discord.py 런타임 이벤트 연결은 배포 후 스테이징 테스트가 필요합니다.
