ABADDON v6.3.3 — 장비·제작 비주얼 진화

[추가 명령어]
- !장비외형 아이템명
- 별칭: !장비비주얼, !강화외형
- Prefix 전용이므로 최상위 슬래시 명령 수는 증가하지 않습니다.

[장비]
- 구매 성공 시 등급·슬롯별 장비 획득 카드 표시
- !장비에서 현재 장착 장비 중 강화 단계가 가장 높은 장비 외형 표시
- 장착 및 장비 감정 완료 시 전용 카드 표시
- 강화 단계가 +5/+7/+10/+12/+15/+18/+20에 도달할수록 룬 문양·광원·실루엣·에너지 날개·오라가 확장
- 강화 실패는 성공 오라 대신 균열 연출 표시

[제작]
- 제작 성공과 실패 결과를 서로 다른 장비 카드로 표시
- 기존 제작 레시피, 실패 확률, 재료 보존, 작업대 수리비 규칙은 변경하지 않음

[유물·감정]
- 땅파기에서 미감정 보물 발견 시 봉인 유물 카드 표시
- 감정 완료 시 등급별 유물 카드 표시
- 등급 상승이 발생하면 감정 반응 문구 추가
- 기존 보물 확률 8%, 감정사 4명, 수수료·매입 배율·등급 상승 확률 유지

[보존]
- 코인 종류·확률, 카지노 탐색 드롭다운, 생활 쿨타임, 돈주세요 1분·50회, 랜덤 인카운트 규칙 유지
- 펫 시스템 로직·수치·성장·진화는 이번 패치에서 변경하지 않음
- !명령어 카테고리 드롭다운과 검색 버튼 유지
