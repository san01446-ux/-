ABADDON v6.3.7 배포·테스트 순서

1) 배포
- 전체본: 기존 저장소의 루트에 풀어 덮어씁니다.
- 패치본: 기존 v6.3.6 저장소 루트에 풀어 덮어씁니다.
- 운영 데이터(survival_data.json)와 .env는 패키지에 포함되지 않습니다. 기존 파일을 유지합니다.
- requirements.txt 기준으로 의존성을 설치한 뒤 Render를 재배포합니다.

2) 가장 먼저 실행할 읽기 전용 테스트
!테스트 상세

정상 기준
- 명령 등록: 통과
- 랜덤 날씨 주기: 2~5시간
- 날씨 종류: 12종
- 돌연변이 구역: 지역/위험 이름 표시
- 오늘의 운세 결정성: 통과
- 장비 데이터: 70종 이상
- 내구도/개조 데이터: 통과
- 카지노 이미지 제거: 첨부 없음
- 전술 전투 후크: 호출 가능
- 명령 이름 유일성: 통과

3) 읽기 중심 기능 확인
!패치노트
!명령어
!날씨
!위험구역
!개조목록

!무기수리 몽둥이

5) 전투 연결 확인
!전투 보통
- 전투 화면에 무기 내구도가 표시되어야 합니다.
- 공격 시 내구도 1, 기술 시 내구도 2가 기본 소모됩니다.

!던전 약함
- 자동 전투 결과에 현재 날씨·운세 보정과 내구도 결과가 표시되어야 합니다.

!지역목록
!지역이동 <오늘의 위험구역 지역명>
!지역탐색
- 위험구역 문구, 성공 보상 배율 또는 실패 피해/감염, 내구도 결과가 표시되어야 합니다.

6) 카지노 확인
!슬롯 100
- 결과와 손익은 표시되지만 카지노 이미지 첨부는 없어야 정상입니다.

7) 홈페이지
- index.html: v6.3.7, 2~5시간 날씨, 신규 기능 8개 카드 확인
- commands.html: 신규 명령어 검색 확인
- updates.html: v6.3.7 최신 카드 확인
- 브라우저 개발자 도구 Network에서 로컬 파일 404가 없어야 합니다.

주의
- 이 환경에서는 discord.py 런타임 패키지를 설치할 수 없어 실제 Discord API 접속·버튼 클릭까지 자동 실행하지 못했습니다.
- Python 컴파일, 명령 등록 스텁 테스트, 주요 콜백 스모크 테스트, 웹 참조 검사와 ZIP 무결성 검사를 수행합니다.
