ABADDON v11.9.0 배포·실제 테스트 가이드

1. 배포
- 기존 데이터 파일과 환경변수를 백업합니다.
- 새 BOT ZIP을 배포합니다.
- Render를 사용한다면 Clear build cache & deploy를 권장합니다.
- 부팅 로그에서 아래 문장을 확인합니다.
  [ABADDON v11.9.0] schedule=guild-local reservations=enabled broadcast=public-only collections=achievements+codex reminders=opt-in-events

2. 기본 검수
!테스트 상세
!1190통합검수 상세
!패치노트

3. 일정센터
- 관리자 계정으로 내일 일정을 등록합니다.
  !일정등록 2026-08-05 21:00 게임 테스트 일정
- 다음 명령으로 노출을 확인합니다.
  !일정
  !오늘일정
  !이번주일정
- !일정삭제 [ID]로 취소 상태를 확인합니다.
- 서버 A에 등록한 일정이 서버 B에 나오지 않는지 확인합니다.

4. 게임 예약
!게임예약 텍사스홀덤 2026-08-05 21:00 10000 아바돈허용
!예약목록
!예약참가 [ID]
!예약취소 [ID]
- 시작 알림에 참가자 수와 방장 시작 명령이 표시되는지 확인합니다.
- 시작 시간이 지난 예약은 한 시간 뒤 종료 상태로 바뀌는지 확인합니다.

5. 카드게임 중계
- 테스트 채널에서 카드게임을 시작합니다.
  !아바돈초대 텍사스홀덤 10000
- 같은 채널에서 실행합니다.
  !중계
  !중계응원
  !중계설정 8 켜기
- 팟·공개 보드·현재 차례가 갱신되는지 확인합니다.
- 쇼다운 전 개인 손패가 중계 메시지에 나오지 않는지 확인합니다.
- !중계종료로 자동 갱신이 멈추는지 확인합니다.

6. 경마 중계
- 경마를 시작하고 말을 선택합니다.
  !경마 10000
- 같은 서버의 텍스트 채널에서 !중계를 실행합니다.
- 6마리 위치, 배당, 선택마, 판돈과 동일 결승선이 표시되는지 확인합니다.
- 경마 중계에 개인 데이터나 다른 서버 경마가 섞이지 않는지 확인합니다.

7. 결승 중계
- 카드게임 종료 후 !최근정산으로 ID를 확인합니다.
- !결승중계 [정산ID]를 실행합니다.
- 승자, 이번 손익, 이전 잔액→현재 잔액이 정산 장부와 같은지 확인합니다.

8. 업적·수집
!업적센터
!업적도감
!수집도감
!화투수집
!포커족보도감
!경마우승마도감
!딜러친밀도
!장식도감
- 같은 명령을 반복해도 업적이 중복 해금되지 않는지 확인합니다.
- !업적전시 [업적ID]로 해금한 항목만 전시되는지 확인합니다.

9. 홈페이지
- / 한국어와 /en/ English가 섞이지 않는지 확인합니다.
- 버전 v11.9.0과 새 일정·중계·수집 섹션을 확인합니다.
- 세 미리보기 이미지와 최신 명령 복사 버튼을 확인합니다.
- ONLINE, 봇 초대, Discord 링크를 확인합니다.

10. 제한 사항
- 게임 예약은 시작 시각에 안전한 시작 명령을 안내합니다. 사람의 확인 없이 판돈을 자동 차감하거나 게임을 강제로 시작하지 않습니다.
- 제작 환경에서는 실제 Discord Gateway와 다중 사용자 동시 클릭을 자동 시험하지 못했습니다.
