ABADDON v6.3.8 배포 및 테스트 순서

1. 전체본 사용
- 저장소 루트에 전체 ZIP을 풀어 덮어쓰기
- 기존 .git 폴더와 Render 환경 변수는 유지

2. 패치본 사용
- apocalypse_bot 폴더가 보이는 저장소 루트에서 패치 ZIP을 풀어 덮어쓰기

3. Render 재시작 로그
- v633_equipment_crafting.py import 구간 통과 확인
- NameError: ebp is not defined가 없어야 함
- v638_hardcore_arcade 등록 이후 봇 로그인 확인

4. 읽기 전용 진단
!테스트 상세
!패치노트
!명령어

5. 1인 기능 테스트

8. 동의형 생물 테러 테스트

주의
- 신규 기능은 실제 칩/식량을 소비함
- 첫 스모크 테스트는 별도 테스트 계정 또는 적은 배팅액 권장
- !테스트 상세는 사용자 재화를 변경하지 않음
