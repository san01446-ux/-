ABADDON v15.0.0 배포·실서버 테스트 가이드

1. 기존 운영 폴더와 데이터 볼륨을 별도로 백업합니다.
2. BOT ZIP의 전체 내용을 기존 소스 위에 덮어씁니다. 데이터 파일은 삭제하지 않습니다.
3. Render 시작 명령과 환경 변수는 기존 값 그대로 유지합니다.
4. 부팅 로그에서 아래 문장을 확인합니다.
   [ABADDON v15.0.0] korean_font=loaded city_renderer=layered components=20 visual_fx=enabled conversation=contextual-bilingual
5. 명령 충돌 상태를 확인합니다.
   !명령등록검수 상세
   !1500통합검수 상세
   !1500시각검수 상세
   !테스트 상세
6. 도시 지도 한글 확인:
   !도시지도
   !도시전경
   사각형 글자(□□□□) 없이 지역 이름이 표시되는지 확인합니다.
7. 꾸미기 적용·복구:
   !도시꾸미기
   부품 선택 → 이동 → 적용 → !도시지도 → !도시꾸미기복구 순서로 확인합니다.
8. 연출 확인:
   !연출설정 화려
   !도시채집
   !도시제작 강화철판 1
   !공격대소환
   !공격대참가
   !차원보스공격
   시작·진행·판정·완료 메시지가 같은 메시지에서 바뀌고 최종 결과가 별도로 남는지 확인합니다.
9. English 확인:
   English 사용자로 !citymap, !fxsettings cinematic, !dimensionexplore, !dimensionraid, !riftbossattack, !chat를 실행합니다.
   English 결과에 한국어 문장이 섞이지 않는지 확인합니다.
10. 대화 확인:
   !대화모드 문맥형
   !말걸기
   "도시 꾸미기가 마음에 들어" → "응응 보스도" → "왜 그렇게 생각해?" 순서로 입력합니다.
   아바돈이 앞선 주제를 유지하는지 확인합니다.
11. 차원·서버 연합망 확인:
   !차원기지
   !항해출발
   !차원탐사
   연합망은 별도 테스트 서버 두 곳에서 양쪽 !연합망 켜기 후 초대·승인을 확인합니다.
12. 홈페이지 ZIP은 정적 호스팅 루트에 전체 업로드합니다.

제작 환경에서 완료한 검사:

- discord.py Gateway가 필요하지 않은 자동 테스트 106개 통과
- v15 전용 정적·자산·웹 테스트 11개 통과
- JavaScript 5개 Node 문법 검사 통과
- 홈페이지 9개 HTML과 모든 로컬 링크 검사 통과
- English HTML 한글 누출 0건
