ABADDON v10.6.0 배포·라이브 점검 가이드

1. 기존 운영 봇과 데이터 폴더를 통째로 백업합니다.
2. 봇 압축을 운영 폴더에 덮어쓰되 기존 사용자 JSON/DB 파일은 삭제하지 않습니다.
3. Python 의존성을 운영 환경과 동일하게 설치한 뒤 봇을 재시작합니다.
4. 시작 로그에서 `[ABADDON v10.6.0] authentic_card_games=16 debt=enabled caps=none seotda=enabled`를 확인합니다.
5. `!게임진행검수`를 실행해 6개 런타임 점검이 모두 정상인지 확인합니다.
6. `!카드게임룰`과 `!cardrules`가 선택 언어에 맞게 따로 표시되는지 확인합니다.

[필수 카드 라이브 테스트]
- `!맞고 10000` → 아바돈 초대 → 내 패 → 패 내기 → 같은 월 선택 → 더미 뒤집기 → 고/스톱.
- `!고스톱 10000` → 생존자 3명 또는 테스트 계정 3명 → 7장/6장/21장 구성을 확인합니다.
- `!아바돈초대 고스톱 10000` → 생존자 1명 + ABADDON + ABADDON-β의 3인 실전 턴 진행을 확인합니다.
- `!아바돈게임 10000` → 카드 16종 선택이 모두 실전 세션으로 연결되고 미니게임 4종도 기존 AI 경로로 실행되는지 확인합니다.
- 폭탄·흔들기 가능한 테스트 패를 구성해 이벤트와 배수가 정산 화면에 표시되는지 확인합니다.
- `!텍사스홀덤 10000` → 블라인드 → 프리플랍·플랍·턴·리버 체크/콜·레이즈·폴드.
- `!포커 10000` → 첫 베팅 → 0~3장 교환 → 마지막 베팅 → 공개.
- `!바둑이 10000` → 세 번 드로우와 네 번 베팅.
- `!섯다 10000` → 첫 장 베팅 → 두 번째 장 베팅 → 족보 공개 및 구사 재경기.
- `!카드블랙잭 10000` → 히트/스탠드 → 딜러 17 이상.
- `!카드바카라 10000` → Player/Banker/Tie 선택 → 서드카드 규칙.

[음수·무상한 테스트]
- 테스트 계정 칩을 1,000으로 낮춘 뒤 `!텍사스홀덤 10000`을 시작해 음수 잔액을 확인합니다.
- 100,000,000 이상의 레이즈를 입력하고 전체 금액이 팟과 잔액에 반영되는지 확인합니다.
- 화투 배수가 겹치는 판을 정산해 16배를 넘어도 잘리지 않는지 확인합니다.
- 패배 후 `!파산신청`의 기존 조건과 복구 흐름을 확인합니다.

[홈페이지]
- 홈페이지 압축을 웹 루트에 덮어씁니다.
- `/`에서 한국어 v10.6.0, 카드 16종, 신규 명령을 확인합니다.
- `/en/`에서 영어 전용 화면과 동일한 16종 정보를 확인합니다.
- 한국어 페이지에 영문 명령 묶음이 섞이지 않고, 영어 페이지에 한글이 노출되지 않는지 확인합니다.

[검수 한계]
이 오프라인 제작 환경에는 discord.py와 Discord 토큰이 없어 실제 로그인·버튼 클릭·메시지 편집을 자동 실행하지 못했습니다. 순수 규칙 테스트, Python 컴파일, 정적 명령 충돌, 웹 문법·링크·언어 분리·압축 무결성은 자동 검수했습니다.
