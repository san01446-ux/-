ABADDON v7.1.1 귀여운 인터랙션 패치
==========================================

패치 주제
- 새로 들어온 서버 멤버가 이름 옆의 🌱 역할 아이콘과 환영 패널로 자연스럽게 적응하도록 개선했습니다.
- 기존 명령어를 삭제하지 않고, 모든 등록된 prefix 명령을 카테고리·검색·페이지·버튼·입력창으로 실행할 수 있게 연결했습니다.
- 잘못된 명령어, 입력값 누락, 쿨타임, 버튼 오류 안내를 귀엽고 이해하기 쉬운 복구 UI로 바꿨습니다.
- 신규 이미지 파일은 추가하거나 변경하지 않았습니다.

1. 신규 멤버 새싹 표식
- 신규 멤버에게 `저 새로 들어왔어요, 환영해주세요!` 역할을 자동으로 부여합니다.
- 기본 유지 기간은 7일이며 1~30일 사이로 변경할 수 있습니다.
- 역할 아이콘을 지원하는 서버에서는 이름 옆에 🌱 아이콘을 표시합니다.
- 유지 기간이 지나면 1시간 주기의 자동 정리 작업이 역할을 제거합니다.
- 봇에게 역할 관리 권한이 없거나 역할 순서가 낮으면 안전하게 건너뛰고 로그를 남깁니다.

관리 명령
- !새싹설정
- !새싹설정 켜기 / 끄기
- !새싹설정 기간 7
- !새싹설정 환영채널
- !새싹설정 아이콘 켜기 / 끄기
- !새싹설정 메시지 켜기 / 끄기
- !새싹역할설치
- !새싹정리

2. 귀여운 환영 패널
- 신규 멤버 입장 시 랜덤 환영 제목·문장·이모지를 표시합니다.
- 가입하기, 정보 보기, 출석하기, 오늘 할 일, 게임 열기, 명령어 도감 버튼을 제공합니다.
- 환영 채널은 설정 채널 → 시스템 채널 → 환영/일반 채널 → 전송 가능한 첫 채널 순으로 탐색합니다.
- 환영 메시지는 신규 멤버 본인만 조작할 수 있습니다.

3. 전체 명령어 버튼 실행
- !명령어와 !귀여운메뉴에서 실행 중인 봇의 visible prefix 명령을 bot.walk_commands()로 동적 수집합니다.
- 전체/기능별 카테고리, 25개 단위 페이지, 검색 입력창을 제공합니다.
- 입력값이 없는 명령은 상세 화면의 바로 실행 버튼으로 실행합니다.
- 입력값이 필요한 명령은 모달 입력창을 연 뒤 실행합니다.
- 기존 !명령어 직접 입력과 기존 별칭은 그대로 유지합니다.
- !처음 화면도 가입·정보·출석·오늘 할 일·게임·명령어 도감 버튼으로 개편했습니다.

신규 대표 명령
- !귀여운메뉴
- !명령패널
- !말랑메뉴
- !버튼명령어

4. 버튼 실행 호환성 보강
- 버튼 실행에서도 기존 명령의 권한 검사, 쿨타임, 콜백, 전역 before/after 훅을 거칩니다.
- v7.0.2 사용자별 명령 잠금과 운영 통계가 버튼 실행에도 적용됩니다.
- 성공한 버튼 실행은 on_command_completion 이벤트를 발생시켜 v7.1.0 성장 활동 집계가 유지됩니다.
- 합성 Context에 invoke/reinvoke, message edit/delete/pin 계열 안전 동작을 추가했습니다.

5. 오류 복구 UI
- 존재하지 않는 명령에는 비슷한 명령 최대 3개와 명령어 찾기 버튼을 표시합니다.
- 필수 입력 누락·잘못된 입력에는 입력 모달로 다시 실행하는 버튼을 제공합니다.
- 동시 실행 잠금과 쿨타임 메시지를 이모지 중심으로 정리했습니다.
- 예상하지 못한 오류에는 사건 번호를 발급하고 명령어 찾기·게임센터·재입력 버튼을 제공합니다.
- 내부 예외 전문은 채팅에 노출하지 않고 서버 로그에 남깁니다.

6. 호환성
- v7.1.0 성장 루프 파일 내용 유지
- v7.0.2 데이터 보호·명령 잠금 유지
- v7.0.0 월드보스 시스템 유지
- v6.5.4 영어 명령어 모듈 파일 내용 유지
- 홈페이지 이미지 127개 추가·삭제·변경 없음
