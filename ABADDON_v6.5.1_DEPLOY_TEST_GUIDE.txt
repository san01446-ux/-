ABADDON v6.5.1 배포 및 테스트 안내
패치 날짜: 2026-08-02

1. 배포
- 가장 안전한 방법: FULL_BOT ZIP의 내용을 기존 저장소 루트에 덮어씁니다.
- PATCH_ONLY ZIP 사용 시 apocalypse_bot 폴더가 보이는 저장소 루트에서 덮어씁니다.
- requirements.txt 변경은 없습니다.
- Render에서 새 배포를 실행하고 봇 로그인 완료 로그를 확인합니다.

2. 기본 점검
!패치노트
!테스트 상세
!명령어
!게임

정상 기준
- !패치노트 제목이 v6.5.1
- 패치 날짜가 2026-08-02
- !명령어에 '카드게임 / 파티'와 '안정화 / 서버 테마' 카테고리가 표시
- !게임에 카드게임 카테고리가 표시

3. 서버 리뉴얼 점검 — 관리자
!서버리뉴얼
!서버리뉴얼 테마목록
!서버리뉴얼 상태
!서버리뉴얼 미리보기 벚꽃정원
!서버리뉴얼 게임미리보기 네온아카데미

정상 기준
- 메인 드롭다운에 20개 서버 관련 항목이 표시
- '28종 테마 미리보기' 선택 후 4개 테마 분류가 표시
- 분류를 고르면 해당 그룹의 최신 테마가 표시
- 실제 적용 전에는 반드시 수동 백업과 미리보기를 먼저 실행

4. 카드게임 점검 — 최소 참가비 권장
!카드게임
!포커 10000
!원카드 10000
!조커잡기 10000

정상 기준
- 참가 버튼을 누른 사용자만 참가자 목록에 추가
- 방장만 인원 확정·시작 가능
- 패 확인은 클릭한 본인에게만 표시
- 시작 전 취소 시 칩 미차감
- 시작 후 시간 초과 시 예약 참가비 환불
- 여러 명이 실제로 참가하는 버튼/턴 테스트는 테스트 서버에서 진행

5. 홈페이지
- OFFICIAL_SITE 전체본을 호스팅 루트에 업로드합니다.
- 메인 버전 v6.5.1과 날짜 2026-08-02를 확인합니다.
- 명령어 페이지에서 '포커', '원카드', '조커잡기', '서버리뉴얼'을 검색합니다.
- 브라우저 캐시가 남으면 강력 새로고침을 실행합니다.

6. 문제 발생 시 수집할 내용
- Render 오류 로그의 첫 Traceback 전체
- 입력한 명령어와 클릭한 버튼
- 발생 시간
- 사용자 수와 참가 단계
- !테스트 상세 결과 화면
